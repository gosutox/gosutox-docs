## Our Zero-Training Pledge

> [!CAUTION]
> **Enterprise Data Protection Guarantee**:
> Under no circumstances is customer proprietary data, conversation history, or uploaded documents used to train or fine-tune public foundational AI models.

### Security Perimeter
* **Encryption in Transit**: Strict TLS 1.3 encryption across all API and WebSocket streams.
* **Encryption at Rest**: AES-256 encryption across all Firestore database collections and Google Cloud Storage buckets.
* **Least-Privilege Workload Identity**: Service-to-service communication is authenticated via Google Workload Identity Federation—zero static API keys.
