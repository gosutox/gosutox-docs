## Overview

Welcome to the official repository for **[docs.gosutox.com](https://docs.gosutox.com)**. This documentation center provides comprehensive architectural overviews, quickstart guides, developer references, and trust disclosures for the Gōsuto X platform and AXON Collaborative AI applications.

Built with modern MDX components and powered by [Mintlify](https://mintlify.com), this repository is styled to reflect the Gōsuto X **Navy Mirage** enterprise design system.

## Local Development & Preview

You can preview the documentation site locally with hot reloading using the Mintlify CLI.

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or later) installed on your system.

### Running the Preview Server

```bash
# 1. Install the Mintlify CLI globally
npm install -g mintlify

# 2. Start the local development server in the repository root
mintlify dev

# 3. View the live preview in your browser (typically at http://localhost:3000)
```

### Validating Links & Schemas

```bash
# Audit the repository for broken links or missing anchors
mintlify broken-links
```
