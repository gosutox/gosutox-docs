## Anatomy of the AXON Interface

AXON features a clean, unified 3-column layout engineered for high-density cognitive workflows:

  <Card title="Right Tools Panel (Context)" icon="sliders">

### 1. Left Sidebar (Session & Folder Tree)
* **Categories & Folders**: Organize client projects, research topics, and department chats into nested folders.
* **Instant Search**: Rapidly filter across hundreds of historical sessions.
* **Background Tasks Indicator**: Monitor ongoing deep multi-step agent tasks in real time.

### 2. Central Canvas (Dynamic Stream)
* **Fluid Stream Engine**: Smooth 60 FPS streaming text rendering with zero lag.
* **Active Decision Badges**: View which live APIs or Brains were queried for each turn.
* **Action Bar**: Instant Copy All, Clear, New Chat, and **Download All PDF/HTML**.

### 3. Right Tools Panel (Context Selector)
* Toggle Brains, Live Data APIs, and Data Files on or off for individual conversation turns without leaving the flow.
