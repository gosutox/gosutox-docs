## What is AXON Agent?

AXON Agent is an autonomous task planning and execution engine. It accepts high-level natural language instructions, decomposes them into structured sub-tasks, and invokes native tools with mathematical precision.

### Key Capabilities
* **Dynamic L1 Gatekeeper**: Evaluates query intent in sub-100ms.
* **Multi-Tool Orchestration**: Seamlessly queries SEC EDGAR, DART, Google Search, and private document Brains.
* **Deterministic Native Fallback**: Gracefully triggers contingency policies when external APIs are unavailable.
