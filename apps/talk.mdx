## Hands-Free Voice Intelligence

AXON Talk provides bi-directional, real-time voice streaming with sub-300ms audio turnaround.

### Features
* **Thin Orchestrator Pattern**: Insulates raw audio WebSocket loops from blocking database I/O.
* **Live Dynamic Thinking**: Real-time contextual reflection before speech synthesis.
* **Context Preservation**: Retains episodic conversation history across streaming turns.
