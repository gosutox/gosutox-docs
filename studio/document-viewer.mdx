## The AXON Document Studio

**Document Studio** is AXON's dedicated document rendering and presentation suite.

### Core Features
* **A4 & Letter Layout Switching**: Seamlessly toggle between international A4 and North American Letter page formats.
* **Dual-Theme Synchronization**: Preview documents in Navy Mirage (Light Mode) or Frost Glass (Dark Mode).
* **Zoom Controls**: Adjust preview scaling from 75% to 150% for detailed proofreading.
* **Interactive Slide Presentation**: Present generated HTML slide decks directly in full-screen mode.
