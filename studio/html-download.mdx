## Zero-Dependency HTML Export

When you click **Download HTML** in Document Studio:
* All responsive CSS styling, typography definitions, and interactive scripts are embedded directly into a **single standalone  file**.
* The file runs flawlessly in any web browser without needing internet access, external libraries, or server dependencies.
* Perfect for sending interactive proposals, presentations, and client reports via email.
