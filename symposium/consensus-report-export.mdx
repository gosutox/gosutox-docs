## The Consensus Report

Upon debate conclusion, Symposium synthesizes:
* **Executive Summary**: Core decision recommendation.
* **Perspective Breakdown**: Key arguments and risks raised by each domain expert.
* **Risk Mitigation Matrix**: Actionable steps to address identified trade-offs.
* **One-Click Export**: Click **Download Report** to immediately open the full analysis in **Document Studio** for A4 PDF printing or HTML download.
